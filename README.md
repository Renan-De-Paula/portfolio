# 📌 Sobre o Projeto

Este projeto é o meu **portfólio profissional oficial**, desenvolvido do zero para centralizar e apresentar minha trajetória como desenvolvedor: competências técnicas, qualificações acadêmicas, certificações em um mapa interativo e a vitrine dos projetos e aplicações web que construí.

### Destaques de Engenharia:
- **Carrossel 3D Cilíndrico:** Navegação imersiva entre os projetos construída com matemática tridimensional pura em JavaScript e CSS 3D transforms.
- **Grafo Interativo Sci-Fi:** Mapa de certificações e competências em rede utilizando `vis-network` para exploração visual dinâmica.
- **Tema Dark/Light:** Alternância completa de paleta de cores com conformidade de contraste e transições suaves.
- **Terminal Digital Rain:** Efeito de chuva digital estilo Matrix renderizado via Canvas HTML5.
- **Mobile-First & Responsividade:** Layout homologado para telas desde smartphones de 320px até monitores ultrawide 4K.

✅ **Carrossel 3D Interativo:** Efeito cilíndrico tridimensional com drag/touch e rotação automática

✅ **Terminal Digital Rain:** Chuva de caracteres no background inspirada no terminal Matrix

# ⚙️ Como Executar o Projeto Localmente

### 1️⃣ Clone o repositório
```bash
git clone https://github.com/Renan-De-Paula/portifolio.git
```

### 2️⃣ Acesse a pasta
```bash
cd portifolio
```

### 3️⃣ Execute no navegador
Basta abrir o arquivo `index.html` com dois cliques, ou utilizar a extensão **Live Server** no VS Code.

Para testar localmente com o Firebase CLI:
```bash
npx firebase-tools serve
```
